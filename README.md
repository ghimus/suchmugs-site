# suchmugs.com

Static company site for Suchmugs S.R.L., served by GitHub Pages at https://suchmugs.com.

Single page, no build step. Edit `index.html`, commit, push - Pages redeploys.
Images in `img/`. `CNAME` binds the apex domain; do not delete it.

Product figures are lifetime units per design (source: Neon `design_units`), and every
product shown is IP-clean per the LHS `IP Status` ledger. Do not add a product here
without checking that ledger first.
